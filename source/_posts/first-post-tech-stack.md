# 你好，世界：我的个人技术博客正式上线

这是我的第一篇博客。

与其把它当成一篇普通的“Hello World”，我更希望把它作为一个起点：从今天开始，把自己的学习、项目、技术实践和思考记录下来。

这个博客本身也是一个小型的技术项目。它不仅仅是一个用来写文章的网站，我也希望通过亲手搭建、修改和维护它，真正理解一个网站从源码到构建，再到部署上线的完整过程。

## 一、为什么要创建这个博客？

学习编程一段时间之后，我越来越发现一个问题：

**学过的东西，如果不真正使用，很容易忘记。**

看过 Spring Boot 的源码和教程，可能过一段时间就忘了。

学习过 Redis、RabbitMQ、MongoDB，也可能只记得一些概念。

看过很多关于 AI Agent、微服务、网络安全的文章，如果没有真正做过项目，知识也很难沉淀下来。

所以我想创建一个属于自己的技术博客。

我希望以后这里记录的不只是“我学会了什么”，还包括：

- 我为什么学习这个技术；
- 它解决了什么问题；
- 我是怎么实现的；
- 实现过程中遇到了什么问题；
- 为什么这样设计；
- 有没有更好的方案；
- 如果重新做一次，我会怎么做。

换句话说，我希望这个博客记录的是一个开发者不断学习、不断实践、不断构建的过程。

## 二、这个博客使用了什么技术？

目前这个博客采用的是比较轻量的静态博客架构。

核心技术栈主要包括：

| 技术 | 作用 |
| --- | --- |
| Hexo | 静态博客生成器 |
| EJS | 页面模板引擎 |
| HTML | 页面结构 |
| CSS | 页面视觉和 Liquid Glass 效果 |
| JavaScript | 页面交互和动态效果 |
| Canvas | 后续用于实现星空背景 |
| Git | 版本管理 |
| GitHub | 源代码托管 |
| GitHub Pages | 博客网站部署 |

整体流程可以理解为：

```text
Markdown
   ↓
Hexo
   ↓
EJS 模板 + CSS + JavaScript
   ↓
静态 HTML / CSS / JS
   ↓
GitHub Pages
   ↓
浏览器
